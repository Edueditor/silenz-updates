# Silenz · atualizações

Página de download do **Silenz**, painel do Premiere Pro que tira os silêncios da fala e junta tudo, com as faixas em sincronia (detecção de voz com IA, roda no seu computador).

**[Baixar a versão mais nova](https://github.com/Edueditor/silenz-updates/releases/latest/download/Silenz_completo.zip)** · o zip traz o plugin (`Silenz.zxp`), o guia em PDF e o link do ZXP Installer. Funciona no Mac e no Windows, com o Premiere em qualquer idioma.

Para atualizar: feche o Premiere e arraste o `Silenz.zxp` novo no ZXP Installer.

O painel lê o arquivo `latest.json` deste repositório uma vez por dia para avisar quando há versão nova.
